## Notes

- Item 2 is a switch for people, not a security boundary: anything that can run commands as the user
  can also write the setting. The skills never turn it on and say so; the real fix (approval outside
  the agent) is C1, planned for v0.18.
- The scout skill's steps 2 to 4 are unchanged (the hash test passes). The install and build flows
  moved to an "Experimental installer (off by default)" section at the end of each skill.
- Many older tests exercised user scope or the old install offer. They now ask for `scope: 'user'`
  through a small shim, or assert the new wording. Plain snapshot `check-clean.plain.txt` changed
  on purpose (the install line).
- README, SECURITY.md and the skills link `docs/reviews/independent-v0.16.1.pdf`, which the owner adds.
- Not done here: the other review findings (C3, C4, C7 to C12, D1 minimization, D3, D6, D7, E1, E2,
  E5, F-series) are not addressed; the installer that holds most of them is off by default.
