## What changed versus v0.8.0

- **The build case is tested now.** v0.8.0's set was trending catalog repos (Install 16, Build 2,
  Either 2; 1 instructions-only). This set is half small: Install 10, Build your own 7, Either 3,
  with 11 of the 20 decided by Claude.
- **Same repo, different answer.** `anthropics/skills`: v0.8.0 said Install for "~16,600 lines of
  Python"; now it's a collection of 20 skills, typical ~100 lines, Install because Anthropic
  maintains it, pointing to `webapp-testing`. `obra/superpowers`: v0.8.0 said Install for ~3,500
  lines; now a collection of 15 skills, and Claude says Build your own for its TDD part.
  `microsoft/playwright-mcp`: v0.8.0 said Either; now Install (vendor, and a thin wrapper around
  Playwright).
- **Claude splits the small skills both ways:** general know-how (prompt engineering, ELI5, a
  well-known LLM-council pattern, TDD) → Build your own; curated rules (Codex CLI model and flag
  details, Chinese anti-template writing rules) → Install, "text only, low risk, check passed".
- **The three named "small" skills are not all small.** `Skill_Seekers` is a 132k-line Python
  tool (Install); `beautify-github-readme` has a 565-line GIF script (Either);
  `agentskills/agentskills` is a spec with a 450-line library (Either). The rules decided those.

## Found on real repos and fixed

`Skill_Seekers` was first read as a collection of 26 skills (its skills are configs; the code is in
`src/`): a collection now needs its code inside its parts, with root tooling (`tools/`) not counted
against it (`wshobson/agents`). Claude's reasons repeated the "(form, time)" label: stripped.

**Known gap:** a remote MCP server named only in the README (`cplj/axiocairn-mcp`, hosted at
axiocairn.com with an OAuth sign-in) reads as "no network"; Claude caught it from the README head.
