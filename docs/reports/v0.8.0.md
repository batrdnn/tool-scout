**Deliberate plain-output changes.** `test/snapshots/all.plain.txt` and `recs-edge.plain.txt`
gain the 3-line shortlist title (item 0). `recs-edge.plain.txt` and `check.plain.txt` gain the

changed. Plain snapshots now update only with `UPDATE_PLAIN_SNAPSHOTS=1`.

**A 5th question option doesn't fit.** AskUserQuestion takes at most 4 options. As agreed,
"Why build vs install?" replaced "Show install steps", and its answer ends with the install steps.

**Found on real repos.** Running the estimate on all 55 catalog repos before writing the review
found 13 defects, each fixed with a regression test (details in `b78fa6d` and `51bad4a`), for
example: `VITE_FIREBASE_API_KEY` read as a "VITE" API, `agents/` inside a skill counted as a plugin,
optional `docker run` counted as required, "OAuth" in an agent list counted as a requirement, and
a topic-based kind overriding the repo's structure.
