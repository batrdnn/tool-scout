## Found along the way

- The first "good enough" bar (strength 0.8) missed `docker`-headed repos: `docker` is a weak keyword
  (0.6 even in the head). It now uses the taxonomy's own `EVIDENCE.headWeak`.
- The ranking-freeze hook blocks read-only Bash commands that name a frozen file and contain `=>`
  (it reads the arrow as a redirect). Worked around with a script file in the scratchpad, not changed.
