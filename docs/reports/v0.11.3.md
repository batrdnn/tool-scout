## The freeze hook, rebuilt through Tool Scout

The hook is personal (`~/.claude/hooks/ranking-freeze/`, entry in `.claude/settings.local.json`), so
its script is not in the repo. It was undone with `scout.mjs undo ranking-freeze` and rebuilt with
`build --scope personal` (plan `ca50e8731e8b`), with both confirmations given by the owner. It now
splits a command at `&&`, `||`, `;`, `|` and newlines outside quotes and judges each piece; a
redirect counts as a write only when a frozen path comes after it. `--start` refused the old
`ranking-freeze` draft on the way, so item 2 was used for real (`--fresh`). The freeze was off
between the undo and the second confirmation.
