## Found by the CI

- Real bugs: `npm test` found no files with Node 20 in PowerShell (cause 16); `audit` mixed `/` and
  `\` and missed a hook's script (14); a hook path with backslashes was refused outright (4);
  `import.meta.dirname` crashed a test file on Node 18 (1).
- Not the code: the three macOS jobs were cancelled in three attempts because GitHub had no macOS
  arm64 runner free ("Due to capacity constraints ... longer queue times"). The fourth attempt got
  runners and passed. The matrix was not changed.
- The items in the request that needed no fix: HOME vs USERPROFILE (see `63b237e`), and symlinks (the
  symlinked-settings test passed on Windows once its mode assertion was skipped; the runners may
  create symlinks). Unicode and color detection in Windows Terminal were already right
  (`supportsUnicode` knows `WT_SESSION`); cause 10 added a test for it and stopped the host
  platform leaking into the old one.
- Skipped on Windows, with the reason in the test: the two privacy tests that need a sh-script
  `claude` (the claude.exe lookup has its own unit tests) and the 0600/0700 mode assertions.

## Design notes

- Tool Scout still never runs a shell. On Windows only `claude.exe` is run; a `claude.cmd` shim is
  refused with what to do instead (documented in the README Requirements).
- CLAUDE.md still says "Node.js 18+" in its conventions section; it was not changed here.
