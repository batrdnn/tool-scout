## Design notes

- The needs file format is now version 3 (new `outside`, `builtins` and `other` fields). An older
  file is re-derived from its saved plan text on `--rematch`, and its rejects are kept.
- A line can have several answers: "an icon, a demo GIF, a FAQ and a launch post" is answered as
  icon, recording (outside), FAQ and post.
- Three existing tests were updated for the new behavior: the README/GIF/FAQ line in the direct
  test, the run 1 regression's direct ids (now with `faq`), and the needs format version.
