## How it stays safe

- **Plan:** reads the repo at one pinned commit and writes nothing outside the data folder.
- **Confirm:** re-makes the plan from scratch at that commit, and refuses if the ID differs, the plan
  expired, it's blocked, or the verdict is "do not install".
- **Skills:** copied from git blobs, each checked against its git hash; never overwritten.
- **Plugins:** `claude plugin marketplace add` + `install`, never `-y`. The repo head must still be the
  pinned commit right before, and the checkout must be it right after, or the install is rolled back.
- **MCP servers:** the README's `claude mcp add`, tokenized without a shell. Shell syntax (even quoted),
  a shell as the server, or an unknown option is refused; `-e`/`-H` values are dropped and named as
  "set yourself".
- **Nothing else runs:** the only process call accepts `claude` and `git -C <dir> rev-parse HEAD`.
