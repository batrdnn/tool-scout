# Tool Scout v0.6: `/tool-scout:me`, your Claude Code animal

Ranking is still frozen. `me` reads the existing profile and changes neither ranking files nor
how recommendations work. There are four items, each with tests written and run red first,
committed one per item. All runs are on 2026-11-24 at `6d9016c`.

## What changed

| item | commit | change |
|---|---|---|
| 1 | `63ca872` | `scout.mjs me [--json]` plus `skills/me/SKILL.md`. The profile is mapped to one of 7 animals, or to the Egg under 10 sessions. The output has original ASCII art, a title, the time window, 3 evidence lines from counts, a superpower, a blind spot, and a close second when the runner-up scores ≥ 0.85 of the winner. It's deterministic: ties go by a fixed order, and the timestamp and key order are ignored |
| 2 | `6551499` | One text-only last line: "Tools that fit a/an <animal>: run /tool-scout:scout". A test checks that `me.mjs` imports no ranking module |
| 3 | `c4d5f70`, `6d9016c` | `me --card out.svg`: a self-contained SVG showing the animal, title, sessions, top language and top topic. Language and topic must be names from the fixed taxonomy. A test fails if any other profile string appears on the card |
| 4 | `d516f2e` | docs/USAGE.md "Your Claude Code animal": the mapping table and rules. A test keeps its thresholds equal to the code. The README has `/tool-scout:me`, "what's my Claude Code animal?" and `me --card` |

Scoring works like this:
- **Score:** each animal's score is its signal ÷ threshold, capped at 2.
- **Thresholds:** Beaver 0.4 (edit share of tool calls), Owl 0.3, Bee 0.5 (sessions with test
  runs), Octopus 3 MCP servers, Ant 6 repeated commands, Fox 8 topics and 3 languages, Turtle 40
  tool calls per session.
- **Source:** the thresholds were set from what each animal means, not tuned to the personas.

## Results

**This machine:** Egg. There are 8 sessions in the last 30 days across 4 projects, not counting
this one. Its hidden scores lean Owl 1.67, Bee 1.25, Ant 1.17.

**Eval personas:** all 3 come out Beaver.

| persona | animal | close second | Beaver score | runner-up score |
|---|---|---|---|---|
| quant-ios | Beaver | Bee | 1.02 | Bee 1.00 |
| webdev | Beaver | none | 0.92 | Fox 0.54 |
| platform | Beaver | Fox | 0.90 | Fox 0.77 |

All three are Beavers because the synthetic sessions contain only Bash and Edit calls, with no
Read or Grep. That puts their edit share at 36–41%. Real history has many more read calls (this
machine: 23%). The thresholds were left as they are.
