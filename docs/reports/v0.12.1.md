## Remaining mediums

- M2 (an http MCP server's target placed without `--`): fix before v1.0. It's a one-line URL check, and today it only fails safe because the claude CLI refuses a missing URL.
- M5 (the scanner misses look-alike letters and soft hyphens): fix before v1.0. NFKC plus confusable folding is cheap, and injection phrasing is the scan's main job.
- M6 (the data folder uses the default umask): fix before v1.0. Plans and the profile hold local paths, and a `--data` folder outside the home folder is readable by other users.
- M8 (a concurrent edit by Claude Code can be lost): accept for v1.0. The rename prevents torn files, the window is milliseconds, and a full fix needs file locking that Claude Code doesn't share.
