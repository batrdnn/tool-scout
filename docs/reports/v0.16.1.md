## Notes

- Item 1: the request said to fetch the flagged line for any medium or high flag. For
  `prompt-injection`, `hidden-instructions`, `obfuscated-exec` and `exfiltration` the line is still
  not shown, and one such flag anywhere in a file blocks every line of that file (the existing rule that the check never echoes injection text, which tests pin). For
  those, the skill offers no install, only the repo link. `invisible-unicode`, `pipe-to-shell`,
  `network-call` and the other flags are shown.
- Item 3: `makePlan` takes `scope = null` and resolves it after reading the README: project for an
  http/sse server, user otherwise. The confirm step plans again with the saved scope, so a plan made
  with the default still confirms. An existing assertion in `security-commands.test.mjs` changed from
  `--scope user` to `--scope project` for an http server.
