**Plain output is unchanged.** 8 commands (`all`, `all --json`, `me`, `rate`, `stats`,
`stats --share`, `dismiss`, `audit`) were captured before and after on the same synthetic user:
byte-identical (JSON differs only in timestamps). `test/snapshots/*.plain.txt` are the old CLI's
own output.

**Inside Claude Code**, the Bash tool's stdout is not a TTY, `CLAUDECODE=1` is set and `TERM` is
still `xterm-256color`; raw escape codes reach the model as text like `[31mRED[0m`. The CLI is
plain there because stdout is not a TTY, and also whenever `CLAUDECODE` is set (checked with a
pseudo-terminal).
