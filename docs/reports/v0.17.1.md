## Notes

- The starter catalog is a copy of the 55-repo snapshot in `test/eval/catalog.json` (a live crawl of
  2026-11-23). It includes a few keyword coincidences that the scout skill's filtering drops. It should
  be regenerated from a fresh crawl before a wide launch. Frozen files were only read, not changed.
- An old (over 20 h) real catalog is now also refreshed in the background rather than in the foreground:
  the run uses what is saved, and the next run uses the fresh crawl.
- Older tests that kept helper files inside the data folder now put the marker there (D6 refuses such a
  folder otherwise). `security-privacy.test.mjs` used an unknown file name to check permissions; it now
  uses one of Tool Scout's own.
- `audit` still names the project folder next to a finding (it is the answer: where the hook is).
- Not done: D7 (disclose profile-dependent GitHub traffic) beyond the privacy text, E5, and the installer
  findings (C3, C4, C7 to C12), which the installer being off by default contains.
