## Notes

- Bee wing color was darkened in item 3 so it gets its own shade; with the tone map in the art round
  the shading no longer depends on color brightness.
- `open` on an `.svg` uses the system's default SVG app, which is usually a browser but not always.
- The skill now writes the card to the plugin data folder on every `/tool-scout:me`, not into the
  current project folder.
